# 🪙 Oman Gold | Gold Price Tracker

A modern, responsive, and user-friendly **Gold Price Tracker Web Application** developed using **Angular, TypeScript, HTML, and Tailwind CSS**.

The application provides an elegant platform for exploring gold prices in Oman, calculating gold values based on weight and karat, and visualizing price trends through interactive charts.

The website features a **Luxury Gold Design**, combining dark navy backgrounds, elegant gold accents, and a clean, modern user interface.

## ✨ Features

### 🏠 Home Page
- Modern and elegant landing page.
- Luxury-inspired user interface.
- Easy navigation between sections.
- Responsive layout for desktop, tablet, and mobile devices.

### 💰 Gold Price Cards
- Displays gold prices for different karats: **24K, 22K, 21K, and 18K**.
- Prices displayed in **Omani Rial (OMR)** per gram.
- Elegant gold-themed cards with hover effects.

### 🧮 Gold Calculator
- Select a gold karat.
- Enter gold weight in grams.
- Automatically calculate the estimated total gold value.
- Instantly update calculations when inputs change.

### 📈 Interactive Gold Price Chart
- Visualizes gold price trends.
- Switch between **7-day and 30-day** periods.
- Dynamic chart updates using Angular Signals.
- Custom SVG-based visualization.

### 📅 Gold Price History
- Displays historical sample gold prices in a structured table.
- Shows daily price increases and decreases.
- Allows filtering records by date.
- Provides a clear view of price changes.

### 📱 Responsive Design
- Mobile-friendly layout.
- Responsive navigation and content sections.
- Built using Tailwind CSS utility classes.

## 🚀 Getting Started

### Prerequisites

Ensure that you have installed:

- Node.js
- npm
- Angular CLI

### Installation

**1. Clone the repository**

```bash
git clone <YOUR-REPOSITORY-URL>
```

**2. Navigate to the project directory**

```bash
cd <PROJECT-FOLDER>
```

**3. Install dependencies**

```bash
npm install
```

**4. Run the development server**

```bash
npx ng serve
```

**5. Open the application**

Visit:

http://localhost:4200/
